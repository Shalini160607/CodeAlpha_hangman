# CodeAlpha Hangman Game

## Description
A simple text-based Hangman game developed using Python.
The player guesses the hidden word by entering one letter at a time.

## Features
- Random word selection
- Maximum 6 incorrect attempts
- Console-based gameplay
- User input handling

## Technologies Used
- Python

## Concepts Used
- Random module
- While loop
- If-else conditions
- Strings
- Lists

## How to Run

1. Download or clone this repository
2. Open terminal
3. Run:

python hangman.py
